CELLULAR DATASET ANALYSIS REPORT
================================================================================

EXECUTIVE SUMMARY
================================================================================

This report provides a comprehensive analysis of the cellular dataframe from the Berlin 
V2X experiment. The dataset contains 207,434 records with 159 columns covering cellular 
network performance, vehicle telemetry, weather data, and traffic information. This is 
the most comprehensive dataset in the Berlin V2X collection, providing multi-dimensional 
insights into V2X communication scenarios.

DATASET OVERVIEW
================================================================================

Total Records: 207,434 measurements
Total Columns: 159 data fields
File Size: 24.44 MB
Memory Usage: 345.35 MB
Data Completeness: 47.6% (significant missing data)
Time Period: GPS timestamp available (ts_gps column)

WHAT THE DATASET PROVIDES
================================================================================

1. CELLULAR NETWORK PERFORMANCE
   - Primary Cell (PCell) measurements: RSRP, RSRQ, RSSI, SNR
   - Secondary Cell (SCell) measurements: Complete carrier aggregation data
   - MCS (Modulation and Coding Scheme) data: 0-31 for both downlink and uplink
   - Resource Block allocation: Detailed RB usage per MCS level
   - Frequency and bandwidth information: Downlink/uplink frequencies, bandwidth
   - Cell identification: Cell ID, TAC, MCC, MNC, Cell Identity
   - Network parameters: E-ARFCN, transmission power, allowed access

2. VEHICLE TELEMETRY DATA
   - GPS coordinates: Latitude, Longitude, Altitude
   - Vehicle dynamics: Speed (km/h), Course Over Ground (COG)
   - Timestamp: GPS timestamp (ts_gps)
   - Position tracking: Reference round position

3. WEATHER AND ENVIRONMENTAL DATA
   - Precipitation: Intensity and probability
   - Temperature: Actual and apparent temperature, dew point
   - Atmospheric conditions: Humidity, pressure, wind speed
   - Visibility: Cloud cover, UV index, visibility
   - Environmental context: Weather conditions during measurements

4. TRAFFIC AND ROAD CONDITIONS
   - Traffic jam factor: Real-time traffic congestion
   - Street information: Traffic street name
   - Distance measurements: Traffic distance
   - Area classification: Geographic area information

5. NETWORK PERFORMANCE METRICS
   - Datarate: Network throughput measurements
   - Jitter: Network latency variation
   - Ping: Network latency measurements
   - Connection quality: Network performance indicators

6. EXPERIMENTAL CONTEXT
   - Device identification: pc1, pc2, pc3, pc4
   - Scenario information: Test scenario (A3D)
   - Drive mode: Platoon driving
   - Target datarate: 350 Mbps
   - Direction: Downlink measurements
   - QoS measurement: Datarate focus
   - Operator: Network operator (1, 2)

WHAT THE DATASET LACKS
================================================================================

1. DATA COMPLETENESS ISSUES
   - 47.6% overall data completeness
   - Significant missing values in many columns
   - Inconsistent data availability across measurements
   - Potential data quality issues

2. TEMPORAL CORRELATION
   - Limited timestamp information
   - No clear temporal ordering
   - Missing time synchronization data
   - No measurement duration information

3. V2X SPECIFIC DATA
   - No direct V2V communication measurements
   - No sidelink or D2D communication data
   - Limited V2I communication context
   - No vehicle-to-vehicle interaction data

4. DETAILED NETWORK ANALYSIS
   - No packet-level analysis
   - No protocol-specific measurements
   - Limited network topology information
   - No handover or mobility data

CONCLUSION
================================================================================

The cellular dataframe is the most comprehensive dataset in the Berlin V2X collection,
providing multi-dimensional insights into V2X communication scenarios. Despite data
completeness issues, it offers excellent potential for SUMO visualization due to its
GPS coordinates, vehicle telemetry, and environmental data. The dataset is particularly
valuable for real-world V2X simulation, network performance visualization, and
environmental impact analysis.

The dataset's strength lies in its comprehensive coverage of V2X communication factors,
making it ideal for creating realistic SUMO simulations that incorporate vehicle
movement, network performance, and environmental conditions. When combined with other
Berlin V2X datasets, it provides a complete picture of V2X communication performance
in real-world scenarios.
