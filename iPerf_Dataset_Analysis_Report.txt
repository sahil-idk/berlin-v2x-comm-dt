IPERF DATASET ANALYSIS REPORT
================================================================================

EXECUTIVE SUMMARY
================================================================================

This report provides a comprehensive analysis of the iPerf dataset containing network 
performance measurements from the Berlin V2X experiment. The dataset consists of 5 
parquet files with a total of 387,535 records measuring network throughput and jitter 
between client devices and a central server.

DATASET OVERVIEW
================================================================================

Total Files: 5 parquet files
Total Records: 387,535 measurements
Total Size: 3.08 MB
Data Completeness: 100% (no missing values)
Time Period: Not specified (no timestamp data available)

File Breakdown:
- pc1.parquet: 57,238 records (0.48 MB) - Client device 1
- pc2.parquet: 39,235 records (0.34 MB) - Client device 2  
- pc3.parquet: 54,192 records (0.46 MB) - Client device 3
- pc4.parquet: 41,928 records (0.35 MB) - Client device 4
- server.parquet: 194,942 records (1.45 MB) - Server measurements

WHAT THE DATASET PROVIDES
================================================================================

1. NETWORK PERFORMANCE METRICS
   - Datarate (throughput): 8,510 to 512,000,000 bits/second
   - Jitter: 0.000 to 101,416,259.240 milliseconds
   - Complete network performance measurements for all connections

2. NETWORK TOPOLOGY INFORMATION
   - Local IP addresses: Client device IPs (10.x.x.x, 100.x.x.x networks)
   - Remote IP addresses: Server IP (193.174.67.58) and external IPs
   - Port information: Local and remote port numbers for each connection
   - Connection mapping: Clear client-server relationship identification

3. MEASUREMENT CONTEXT
   - Measurement ID: Sequential measurement numbering
   - Device identification: Clear separation between client devices (pc1-pc4) and server
   - Connection tracking: Multiple concurrent connections per device

4. DATA QUALITY
   - 100% data completeness across all files
   - Consistent schema across all files
   - No missing or corrupted values
   - High precision measurements

WHAT THE DATASET LACKS
================================================================================

1. TEMPORAL INFORMATION
   - No timestamps or time-based data
   - Cannot determine measurement timing or duration
   - No chronological ordering of measurements
   - Cannot correlate with other datasets temporally

2. SPATIAL/GPS DATA
   - No GPS coordinates or location information
   - No vehicle position data
   - No spatial context for network measurements
   - Cannot map measurements to physical locations

3. VEHICLE TELEMETRY
   - No speed, direction, or movement data
   - No vehicle identification beyond IP addresses
   - No traffic or road condition information
   - No weather or environmental data

4. CONTEXTUAL INFORMATION
   - No test scenario descriptions
   - No network configuration details
   - No measurement methodology information
   - No quality of service parameters

CONCLUSION
================================================================================

The iPerf dataset provides valuable network performance measurements for V2X research
but lacks spatial and temporal context for direct SUMO visualization. While it cannot
be used alone for vehicle simulation, it offers excellent opportunities for network
topology visualization and performance-based simulation approaches. The dataset's
strength lies in its comprehensive network performance data and 100% data completeness,
making it ideal for network analysis and validation of other V2X measurements.

The dataset is most valuable when integrated with other Berlin V2X datasets (cellular,
sidelink) to provide a complete picture of V2X communication performance across
different technologies and scenarios.
